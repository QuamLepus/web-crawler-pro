MCP & SDKs

The platform is an API first: agents, notebooks and CI call the same endpoints the console does. The MCP server exposes the useful subset as tools, so a coding assistant can search, ask, watch and check provenance without a bespoke integration.

Call it

curl -s {{ base }}/mcp \
  -H "Authorization: Bearer $WCP_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"ask","arguments":{"question":"Who sets EU AI rules?"}}}'

Python

pip install webintelligence

from webintelligence import Client

client = Client(token=os.environ["WCP_TOKEN"])
answer = client.ask("average Pixel price in Bangladesh")
print(answer.text, answer.confidence)
for cite in answer.citations:
    print(cite.url, cite.fetched_at)

client.watch.create(
    name="competitor pricing",
    urls=["https://competitor.test/pricing"],
    schedule="6h",
)

The SDK is a thin typed wrapper over the REST API — nothing it does is unavailable over HTTP.

TypeScript

npm i @webintelligence/sdk

const client = new WebIntelligence({ token: process.env.WCP_TOKEN! });
const report = await client.research("2026 cloud pricing, Bangladesh");
console.log(report.markdown);
