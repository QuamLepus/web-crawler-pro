Workflows

Build and run robots-aware crawl steps, including dependency-based branches.

Workflows support up to 10 crawl steps and 25 pages per step. DAG steps run serially; a failed step skips its descendants while independent branches continue. Runs require a configured Celery worker.

Create crawl workflow

Advanced: define step IDs and dependencies

Enter a JSON array of step objects. Each step needs a URL. Use a unique step_id and depends_on list for branching; an empty list marks a root step. Omit dependencies to keep the previous-step sequence.

The advanced JSON field takes precedence over the URL list. Robots.txt checks are enabled in the simple form; scheduled runs require Celery Beat and workers.
