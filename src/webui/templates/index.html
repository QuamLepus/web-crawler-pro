{# ── operations ── #}

Big builds belong on a schedule, not in a web request. The same engine runs from the CLI and inside GitHub Actions (public repos: unmetered minutes).

# level 0 — ~330 MB, Ctrl-C safe, resumes after every shard wcp search-index build --level 0

# train the spelling dictionary from your own vocabulary wcp search-index spell --check "kubernets,reserch"

# pre-compute vectors so reranking is a lookup, not a model call wcp search-index embeddings

# monthly refresh — only pages whose text actually changed are re-indexed wcp search-index refresh --snapshot CC-MAIN-2026-40

Sizing

Common Crawl WET runs about 2.78 KB per page compressed. 10M pages ≈ 28 GB; 100M ≈ 280 GB. Budget disk, then forget about per-query pricing entirely.

Where to run it

A laptop is enough for level 0. For levels 2–3, GitHub Actions (6-hour job cap) or any machine with a big disk — the builder is resumable, so a killed run costs nothing.
