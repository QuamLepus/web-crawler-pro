The healing ladder

  1. schema.org JSON-LD — the page's own machine-readable claim.
  2. OpenGraph / microdata — weaker, still the page's claim.
  3. the recipe's selectors, in priority order.
  4. label lookup — “Price” next to a value, anywhere on the page.
  5. explicit failure for a required field.

A healed field is reported as healed and costs confidence, so a dataset built from a redesigned page carries that fact into its provenance instead of silently mixing two schemas.

Publish one

wcp recipes draft https://shop.test/p/1 \\
    --name shop --host shop.test

wcp recipes test shop            # fixtures first
wcp recipes publish shop@1.2.0   # bundle + digest
wcp install shop@1.2.0           # on another box

Publishing writes the recipe with its tests and a digest over both. Installing re-runs those tests before the recipe is trusted.
