What it is

Four jobs, one platform

This is infrastructure for turning the open web into a dataset you control. It is not a search engine for the public, and it is not a shop — every screen maps to one of these four jobs.

🕷

Crawl

A Redis-backed frontier with per-host politeness, priority queues and an optional stealth ladder for sites that need one.

POST /api/v1/jobs/crawl
✦

Discover

Describe a topic in one sentence, get a ranked shortlist of the right websites — with the reasoning shown, and nothing crawled until you approve.

POST /api/v1/discovery
🧪

Refine

Cleaning, language detection, PII redaction and MinHash/SimHash de-duplication, exported as JSONL, CSV, Parquet or straight to object storage.

src/pipeline/*
🗂

Index

BM25 with authority boosting over Curlie, Wikipedia and Common Crawl. Queried locally, offline-capable, no third-party search API.

GET /api/v1/search-index/query

Run the whole thing from a terminal

no console required
# 1 — turn a sentence into a shortlist of sites (crawls nothing) wcp discover --topic "solar panel installers" --count 20 --preview

# 2 — approve and crawl them wcp crawl --discovery disc_9f8020bd165e

# 3 — build an index you own, from free datasets wcp search-index build --level 0 # ~330 MB
wcp search-index query --q "photovoltaic research"

How ranking works

no black box

1 · BM25 shortlist

Classic term-frequency scoring over shards, capped term frequency so a keyword-stuffed page cannot win.

2 · Authority boost

Open PageRank (0–10) multiplies the score, so a university page outranks a scraper of that university.

3 · Optional rerank

An encoder reorders the shortlist. No model installed? The engine says so and hands you BM25 results.

score = bm25 × (1 + authority_weight × authority / 10) — and it is spelled against your own vocabulary, so kubernetes never becomes kubernets.
