From a sentence to a dataset

Four steps. Each one is independently useful, and each one is a documented API call.

Describe it

“best budget laptops 2026” — a topic, not a list of URLs. Seeds are optional.

Get a shortlist

Ranked candidates with the reasoning shown. Preview it for free before anything is crawled.

Approve and crawl

Pick the domains you trust. Politeness, stealth and proxies are handled per host.

Query or export

JSONL, CSV, Parquet, webhooks — or ask your own index, which costs nothing per query.

Discovery in one request

No URLs. You describe the topic; the engine finds the sites and explains each score.

# 1 — preview, crawls nothing curl -X POST {{ request.base_url }}api/v1/discovery/preview \

  -d '{"topic":"open source search engine","count":20}'
