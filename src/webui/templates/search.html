How a score is built

  1. BM25 shortlists candidates across every shard.
  2. Phrase and exclusion filters are verified against the real document, which is why they are not stored in the index.
  3. Authority (Open PageRank 0–10) multiplies the score.
  4. Reranker, if one is loaded, reorders the shortlist.
  5. Host collapse keeps one result per site so discovery returns websites, not pages.
score = bm25 × (1 + 0.35 × authority / 10)

Why own it

  • ✓ $0 per query — the cost is disk and one build
  • ✓ Works with the network unplugged
  • ✓ You can explain every result, because you chose the corpus
  • ✓ Nobody can change ranking underneath you
