Errors

401
Missing or expired credentials
402
Quota exhausted — the plan ceiling or overage
404
Not yours, or not there
409
Conflict — an org or email already exists
422
Validation failed; the body says which field
429
Rate limited — honour Retry-After

Every error body is {"detail": "…"}, which is exactly what the console shows in its toasts.

Authentication

# long-lived key, for machines curl {{ request.base_url }}api/v1/jobs -H "X-API-Key: $KEY"

# JWT, after POST /api/auth/login curl {{ request.base_url }}api/v1/jobs -H "Authorization: Bearer $TOKEN"

A complete round trip

# 1 — create a workspace and grab a token TOKEN=$(curl -s -X POST {{ request.base_url }}api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"org_name":"Acme","email":"me@acme.test","password":"correct-horse"}' \
  | jq -r .access_token)

# 2 — see what a topic turns up, crawling nothing curl -s -X POST {{ request.base_url }}api/v1/discovery/preview \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"topic":"solar panel installers","count":20}' | jq

# 3 — queue a real crawl curl -s -X POST {{ request.base_url }}api/v1/jobs/crawl \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","max_pages":50}' | jq

# 4 — query your own index (free, offline-capable) curl -s "{{ request.base_url }}api/v1/search-index/query?q=solar+energy" \
  -H "Authorization: Bearer $TOKEN" | jq
